# Changelog

Notable changes to `@benomad/msdk-mcp`, the MCP server of the BeNomad MSDK for Android, in the
[Keep a Changelog](https://keepachangelog.com/) format. Each release documents one MSDK version and carries its
number; this file lists the changes to the server and the package themselves.

## [Unreleased]

First version.

### Added

- The public API reference of the MSDK, exported from its published reference: every class, function and property,
  with its signature, parameters and documentation. One release per MSDK version.
- The module pages and guides, whole or by section.
- `msdk_status`, `msdk_get_started`, `msdk_search_docs`, `msdk_get_api` and `msdk_get_guide`, all read-only.
- Search over the API names (`Core.init`, `initCore`) and the guides, in British and American spelling.
- MCP 2026-07-28 and the 2025 revisions, over stdio; Node.js 20 or later.
- Install notes for Claude Code, Claude Desktop, Cursor, VS Code Copilot, Codex, Gemini CLI, Zed and Devin Desktop:
  from the Desktop extension, the package, or a clone of the repository; the files on each release's page, with
  their SHA-256 checksums.
- Claude Desktop extension, with the notices of the open-source packages it includes.
- BeNomad's proprietary licence: free to use, unmodified, with the MSDK.
